
## Data Model

| Column | Description |
|---|---|
| `EVENT_ID` | Unique identifier for each event |
| `EVENT_TYPE` | Type of social media interaction |
| `USER_ID` | Identifier of the user generating the event |
| `POST_ID` | Identifier of the related post |
| `HASHTAG` | Hashtag associated with the post |
| `TIMESTAMP` | Time the event occurred |
| `INGESTED_AT` | Time the event was ingested into Snowflake |
